# ข้อมูลบริษัท Alpha Prime Fulfillment

## เกี่ยวกับบริษัท

บริษัท อัลฟ่า ไพรม์ ฟูลฟิลเมนท์ จำกัด หรือ Alpha Prime Fulfillment (APF) ให้บริการด้านคลังสินค้า โลจิสติกส์ และ Fulfillment แบบครบวงจรสำหรับองค์กร ธุรกิจ SME ธุรกิจ B2B, B2C และ E-commerce

บริการครอบคลุมตั้งแต่การรับสินค้าเข้าคลัง การตรวจสอบและเตรียมสินค้า การจัดเก็บ การจัดการคำสั่งซื้อ การหยิบและแพ็กสินค้า การคัดแยก การจัดส่ง ไปจนถึงการจัดการสินค้าคืน พร้อมระบบติดตามข้อมูลเพื่อช่วยให้การดำเนินงานมีความแม่นยำ รวดเร็ว ปลอดภัย และรองรับการเติบโตของธุรกิจ

## บริการของ APF

APF ให้บริการหลัก 4 ด้าน ได้แก่

1. B2B Fulfillment Services
2. B2C Fulfillment Services
3. Warehousing Management
4. Transportation Services

# B2B Fulfillment Services

บริการจัดการ Supply Chain สำหรับองค์กรและธุรกิจ SME ครอบคลุมการบริหารคลังสินค้า การจัดการคำสั่งซื้อ และการกระจายสินค้าไปยังปลายทางทั่วประเทศ

บริการ B2B Fulfillment ช่วยลดภาระในการบริหารคลังสินค้า เพิ่มความถูกต้องของข้อมูลสต็อก รองรับการเติบโตของธุรกิจ และช่วยให้ลูกค้าตรวจสอบข้อมูลได้ในแต่ละขั้นตอน

# B2C Fulfillment Services

บริการ Fulfillment แบบครบวงจรสำหรับธุรกิจ B2C และ E-commerce ตั้งแต่การรับคำสั่งซื้อจนถึงการจัดส่งสินค้าให้ผู้บริโภค

ระบบสามารถรวบรวมคำสั่งซื้อจากช่องทางออนไลน์ต่าง ๆ เพื่อช่วยให้การจัดการคำสั่งซื้อรวดเร็วและแม่นยำ พร้อมรองรับปริมาณคำสั่งซื้อที่เพิ่มขึ้นตามการเติบโตของธุรกิจ

บริการครอบคลุม

- การเชื่อมต่อคำสั่งซื้อจากช่องทางต่าง ๆ
- การประมวลผลคำสั่งซื้อ
- การหยิบสินค้า
- การแพ็กสินค้า
- การจัดส่งสินค้า
- การติดตามสถานะ
- การจัดการสินค้าคืน

# Warehousing Management

บริการบริหารจัดการคลังสินค้า ครอบคลุมการรับสินค้า การตรวจสอบคุณภาพ การจัดเก็บ การเคลื่อนย้าย การตรวจสอบสต็อก และการแพ็กสินค้า

ระบบบริหารคลังสินค้าของ APF ช่วยให้สามารถตรวจสอบสินค้าและข้อมูลสต็อกได้แบบ Real-time พร้อมใช้ระบบบาร์โค้ดในขั้นตอนสำคัญเพื่อลดข้อผิดพลาดในการดำเนินงาน

# Transportation Services

บริการบริหารจัดการและขนส่งสินค้าทั่วประเทศ รองรับการจัดส่งสินค้าหลายช่องทาง พร้อมระบบติดตามสถานะการจัดส่ง

บริการครอบคลุม

- การบริหารจัดการงานขนส่ง
- การมอบหมายงานจัดส่ง
- การรับและจัดส่งสินค้าสำหรับพนักงานขับรถ
- การแสดงภาพรวมและสถานะการจัดส่ง
- การเชื่อมต่อกับบริษัทขนส่งหลายราย
- การติดตามสถานะการจัดส่งแบบ Real-time
- การติดตามสถานะผ่านระบบ ShipXpress

# กระบวนการให้บริการ Fulfillment

APF ให้บริการจัดการสินค้าตั้งแต่การรับสินค้าเข้าคลังจนถึงการจัดส่ง โดยแบ่งเป็น 7 ขั้นตอน ดังนี้

## 1. Inbound – รับสินค้าเข้า

- รองรับงานทั้ง B2C และ B2B
- รองรับงานรับคืนสินค้า หรือ Return
- ตรวจนับและตรวจสอบคุณภาพสินค้า

## 2. Pre-work – ตรวจสอบและเตรียมสินค้า

- ติดฉลากหรือเปลี่ยนบรรจุภัณฑ์
- คัดแยกสินค้าตามเงื่อนไข
- ตรวจสอบคุณภาพสินค้า หรือ QC

## 3. Storage – จัดเก็บสินค้า

- รองรับระบบ ASRS สำหรับจัดเก็บสินค้าแบบ Full Pallet
- รองรับระบบ Mini Load สำหรับสินค้าชิ้นเล็ก
- รองรับการจัดเก็บสินค้าที่มีความหนาแน่นสูง

## 4. Picking – หยิบสินค้า

- รองรับคำสั่งซื้อทั้ง B2C และ B2B
- หยิบสินค้าตาม Order แบบ Real-time
- รองรับคำสั่งซื้อจากหลายช่องทางการขาย

## 5. Packing – แพ็กสินค้า

- แพ็กสินค้าตามมาตรฐาน
- ตรวจสอบคุณภาพก่อนจัดส่ง
- ติดฉลากและแนบเอกสารสำหรับการจัดส่ง

## 6. Sorting – คัดแยกตามปลายทาง

- แยกสินค้าตามกลุ่มขนส่งหรือพื้นที่จัดส่ง
- แยกสินค้าตามประเภทคำสั่งซื้อ
- รองรับการจัดส่งผ่านผู้ให้บริการขนส่งหลายช่องทาง

## 7. Shipping – จัดส่งสินค้า

- รองรับการจัดส่งทั้ง B2C และ B2B
- เชื่อมต่อกับบริษัทขนส่งหลายราย
- ติดตามสถานะการจัดส่งแบบ Real-time

# ระบบบริหารจัดการคลังสินค้า

## การรับสินค้าเข้าคลัง

- รองรับการนำเข้าข้อมูลสินค้าครั้งแรกด้วยไฟล์ Excel
- รับสินค้าจาก Vendor โดยอ้างอิงข้อมูลจากเอกสาร
- ใช้ระบบ ShipX Client Ops ในขั้นตอนการรับสินค้า
- ลูกค้าสามารถกำหนด Checklist สำหรับตรวจสอบคุณภาพสินค้าได้
- รองรับการบันทึกวิดีโอระหว่างการตรวจสอบคุณภาพสินค้า

## การหยิบและเคลื่อนย้ายสินค้า

ระบบรองรับการหยิบและเคลื่อนย้ายสินค้าภายในคลัง พร้อมตรวจสอบสินค้าและสต็อกด้วยบาร์โค้ด เพื่อช่วยลดความผิดพลาดในการปฏิบัติงาน

## การจัดการสินค้าและตำแหน่งจัดเก็บ

ระบบรองรับการเพิ่มสินค้าใหม่พร้อมบันทึกรายละเอียดสินค้า รวมถึงการจัดการตำแหน่งและปริมาตรของพื้นที่จัดเก็บ โดยกำหนดให้ 1 Location จัดเก็บสินค้า 1 SKU

## การตรวจสอบการแพ็กสินค้า

ระบบตรวจสอบสินค้าด้วยการสแกนบาร์โค้ดในแต่ละขั้นตอน ได้แก่

1. สแกน Packing Slip ของคำสั่งซื้อ
2. สแกนบาร์โค้ดสินค้า
3. สแกน Serial Number ของสินค้า
4. สแกน Label เพื่อยืนยันและปิดพัสดุ

ระบบสามารถสร้าง Packing Slip สำหรับคำสั่งซื้อแต่ละรายการ และบันทึกวิดีโอระหว่างกระบวนการแพ็กสินค้าเพื่อใช้ตรวจสอบย้อนหลัง ผู้ใช้งานสามารถเลือกเลขที่คำสั่งซื้อเพื่อดูรายละเอียดและดาวน์โหลดวิดีโอได้

# ระบบที่ใช้ในการดำเนินงาน

## Warehouse Management System หรือ WMS

ระบบบริหารจัดการคลังสินค้า ครอบคลุมการรับสินค้า การตรวจสอบคุณภาพ การจัดเก็บ การหยิบ การเคลื่อนย้าย การตรวจสอบสต็อก และการแพ็กสินค้า

## Order Management System หรือ OMS

ระบบบริหารจัดการคำสั่งซื้อ สามารถเชื่อมต่อผ่าน API เพื่อรวบรวมและจัดการคำสั่งซื้อจากแพลตฟอร์มออนไลน์ต่าง ๆ ไว้ในระบบเดียวโดยอัตโนมัติ

ความสามารถของระบบประกอบด้วย

- รวบรวมคำสั่งซื้อจากหลายแพลตฟอร์ม
- จัดการคำสั่งซื้อจากส่วนกลาง
- รองรับการสร้างคำสั่งซื้อใหม่
- รองรับคำสั่งซื้อพิเศษที่ต้องสร้างแยก
- เลือกเลขที่คำสั่งซื้อเพื่อตรวจสอบรายละเอียด
- ตรวจสอบวิดีโอกระบวนการแพ็กสินค้า
- ดาวน์โหลดวิดีโอเพื่อตรวจสอบย้อนหลัง

## Product Management

ระบบจัดการข้อมูลสินค้า รองรับการเพิ่มสินค้าใหม่พร้อมบันทึกรายละเอียดสินค้าอย่างครบถ้วน รวมถึงการสร้างสินค้าแบบ Bundle โดยนำสินค้าหลายรายการมารวมเป็นชุดเดียวกัน

ประโยชน์ของการจำหน่ายสินค้าแบบ Bundle

- เพิ่มโอกาสในการขายสินค้าเป็นชุด
- เพิ่มมูลค่าเฉลี่ยต่อคำสั่งซื้อ หรือ Average Order Value
- ช่วยให้สินค้าหมุนเวียนเร็วขึ้น
- ช่วยระบายสินค้าที่ขายช้าหรือใกล้หมดอายุ
- ช่วยแนะนำสินค้าใหม่ให้ลูกค้าทดลองใช้
- ลดต้นทุนการจัดส่งจากการรวมสินค้าไว้ในพัสดุเดียว

## Transportation Management System หรือ TMS

ระบบบริหารจัดการการขนส่ง ใช้สำหรับควบคุม มอบหมาย และติดตามกระบวนการจัดส่งสินค้า

ความสามารถของระบบประกอบด้วย

- แสดงภาพรวมการจัดส่งผ่าน Delivery Overview Dashboard
- แสดงสถานะของงานจัดส่ง
- มอบหมายคำสั่งซื้อหรืองานจัดส่ง
- จัดการการรับและส่งสินค้าสำหรับพนักงานขับรถ
- ติดตามสถานะการจัดส่งผ่านระบบ ShipXpress
- รองรับการ Track & Trace

# รายงานและการตรวจสอบข้อมูล

ระบบมีรายงานสรุปข้อมูลแบบรายวันและรายเดือน โดยผู้ใช้งานสามารถเลือกช่วงวันที่ที่ต้องการตรวจสอบได้

ข้อมูลในรายงานประกอบด้วย

- คำสั่งซื้อทั้งหมดในช่วงเวลาที่เลือก
- จำนวนคำสั่งซื้อแยกตามสถานะ
- กราฟวิเคราะห์จำนวนคำสั่งซื้อและยอดขายรายชั่วโมง

# สรุปภาพรวม

Alpha Prime Fulfillment ให้บริการด้านคลังสินค้า โลจิสติกส์ และ Fulfillment แบบครบวงจร ตั้งแต่การรับและตรวจสอบสินค้า การจัดเก็บ การจัดการคำสั่งซื้อ การหยิบและแพ็ก การคัดแยก การขนส่งทั่วประเทศ ไปจนถึงการจัดการสินค้าคืน

APF ใช้ระบบ WMS, OMS และ TMS ในการบริหารจัดการ พร้อมระบบตรวจสอบด้วยบาร์โค้ด การบันทึกวิดีโอในขั้นตอนสำคัญ และการติดตามข้อมูลแบบ Real-time เพื่อช่วยให้ลูกค้าตรวจสอบการดำเนินงานได้อย่างถูกต้องและมีประสิทธิภาพ
